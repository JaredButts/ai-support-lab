# AI Support Lab

A collection of hands-on technical case studies documenting real debugging work with APIs, authentication protocols, and AI-assisted tooling.

## Case Studies

### [Debugging Google OAuth 2.0 in Postman](oauth2-case-study.md)
A step-by-step walkthrough of configuring an Authorization Code grant flow against the Google Calendar API in Postman, including two real errors encountered and fixed:
- `redirect_uri_mismatch` (Error 400)
- `access_denied` (Error 403, unverified app)

Includes plain-language explanations of Authorization Code Grant, Access Tokens, Refresh Tokens, and Scopes.
